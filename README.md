# Akash Kondimoena – AI/ML Engineer Portfolio

A modern and responsive personal portfolio website developed for **Akash Kondimoena**, an AI/ML Engineer with 4+ years of experience in Artificial Intelligence, Machine Learning, Generative AI, Large Language Models (LLMs), and Natural Language Processing (NLP).

The portfolio showcases professional experience, technical expertise, education, and contact information through a clean and interactive user interface.

---

## About

This portfolio is designed to highlight Akash Kondimoena's professional profile, technical skills, work experience, and educational background. It provides visitors with an overview of his expertise in AI/ML technologies while maintaining a responsive and user-friendly design across all devices.

2. Open the project folder.

3. npm i or npm install ( optional )

4. Open `index.html` in your browser.
